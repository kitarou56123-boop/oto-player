# おとプレイヤー

自分専用の高音質 音楽・動画プレイヤー（Android）。

- スマホ内の音楽・動画を自動で探して一覧表示、検索
- ほぼすべての形式を再生（VLCエンジン：FLAC, ALAC, APE, DSD, WMA, MKV, AVI, WMV など）
- 10バンドイコライザー、重低音、音割れ防止、フラット時は無加工
- 画面を消しても再生、Bluetoothスピーカーのボタン対応
